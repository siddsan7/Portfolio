# Remaining release work

Implementation, council review and verification are documented in docs/verification/report.md.

- Obtain explicit owner deployment approval. Git-triggered deployment is disabled.
- Configure and verify the primary domain/HTTPS and alternate-host redirects after approval. Do not change DNS implicitly.
- Verify actual hosting status codes, headers, protection and crawler access; local tests alone do not prove Vercel behavior.
- Check absolute public social image and résumé URLs and real social unfurls after launch.
- Complete Search Console and Bing Webmaster Tools ownership verification; submit the sitemap after approval.
- Have an unfamiliar person and a screen-reader user check role → project → résumé → contact.
- Measure field Core Web Vitals when enough real traffic exists. Lab measurements do not establish p75 field LCP/INP/CLS.
- Replace concept visuals only when verified product captures exist. This is optional polish, not a reason to mislabel current artwork.

Do not invent achievements, dates, metrics, demos, affiliations or client outcomes. Sole project authorship was confirmed by the owner; project dates were explicitly waived.
