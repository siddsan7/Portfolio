# Architecture map

- Entry: `redesign.html` → Vite bootstrap/CSS (`src/redesign/bootstrap.js`) → dynamically imported navigation (`client.jsx`) after eager resources, font, hero decode, and a painted frame; legacy `index.html`/main/App are not build inputs.
- Build: `scripts/build-static.js` first bundles the header island/CSS, then SSR-compiles `src/redesign/entry.jsx` to ignored `.build/`, calls React renderToStaticMarkup, emits five public pages, six noindex archive pages, 404, sitemap and shared metadata.
- Content: `src/redesign/content.js` owns identity, projects, contribution copy, skills (area/tools pairs without project links), routes and aliases. `caseStudies.js` owns pinned revisions, evidence tables, decision stories, flows and walkthroughs. `resume.js` owns source-verified education/experience, also shown before homepage projects. See `docs/hiring-refresh.md` for acceptance and evidence gaps.
- View: `Site.jsx` composes pages; `CaseStudy.jsx` standardizes facts, actual screenshots, evidence, architecture, decisions, walkthrough and scope. `ArrowLink.jsx` shares link styling. About uses the owner's LinkedIn portrait. `Artwork.jsx` retains homepage concepts (sharp local SVGs for ToneScope/Dispatcher); all images are local. Visual provenance: `docs/visuals/` and `public/assets/artwork/README.md`. `styles.css` centralizes layout, print and reduced motion.
- Browser: only `Navigation.jsx` hydrates; `calculator.js` progressively enhances the optional Dispatcher arithmetic example with validation and reset. Native source formula remains without JavaScript. Anchors/details remain native. IntersectionObserver tracks section boundaries/bottom; ResizeObserver tracks header height. No runtime data service or SPA router is required.
- Serving: directory indexes and 404.html. `serve-static.js` mirrors strict local status/redirect behavior, gzip and cache behavior. `vercel.json` removes blanket fallback, normalizes slash/host/old routes, and disables Git-triggered deployment until owner release review.
- Assets: local Karrik/OFL, favicon, social PNG, two-page selectable résumé PDF. `qa-browser.mjs --assets` regenerates PDF/PNG. PDF links normalize to canonical HTTPS, independently checked by `check-pdf.py`.
- Checks: lint; build; `check-static.js` HTTP/HTML/link/indexing contracts; `check-preview.js` preview noindex then production restore; artwork hashes/initial-script budget; three-run mobile LCP gate in check-lcp.mjs; optional external Playwright/axe/Lighthouse via qa-browser.mjs; PDF facts/annotations via pypdf. Never build while browser capture is active.
- Evidence: docs/verification final captures and compact JSON; raw Lighthouse logs ignored in `.build/`.
- Legacy: old src/components/pages/profile/skills/experience retained untouched to preserve pre-existing edits; `src/data/projects.js` only feeds labeled archived pages. No old placeholder content is promoted into current evidence.
